# 识典古籍

识典古籍是字节跳动（北京抖音信息服务有限公司开发运营）与北京大学数字人文研究中心合作建设的古籍智能检索、阅读与整理平台，汇集四库全书、四部丛刊、历代正史、地方志、类书及海内外藏书机构的古籍影像，提供繁体标点整理文本、原书影像对照、AI 白话译文，并开放"边读边校"的众包校对。

- 网站链接：https://www.shidianguji.com/
- 分享协议：[识典古籍用户服务协议](https://www.shidianguji.com/protocol/page)（平台内容知识产权归运营方所有；未经书面许可不得复制、镜像、抓取、下载；北京大学提供的古籍图文数据版权归北京大学所有，见[关于我们](https://www.shidianguji.com/aboutus/page)）
- 规模：截至 2026 年 7 月已免费公开超 7 万部古籍（[中新网 2026-09-01](https://www.chinanews.com.cn/cj/2026/09-01/10687722.shtml)）；2026-09 实测网站书目 sitemap 列出约 7.7 万个书籍页面
- 资源类型：整理文本（繁体、标点、分段）、原书影像、AI 白话译文；涵盖经史子集、道教、佛教、地方志、类书（如《古今图书集成》）、正史等
- 不支持 IIIF 协议
- **注意**：用户协议明确禁止以机器人、蜘蛛等程序监视、复制、镜像、下载站内内容，网站也部署了字节跳动反爬虫保护；仅适合在线阅读和少量引用

## 搜索与浏览

- 搜索页面：https://www.shidianguji.com/ 首页搜索框，输入书名、人名或任意词句即可
- 搜索是**全文检索**：不仅匹配书名，还会命中正文段落，并显示所在书、章节和上下文；同时会推荐相关书目
- 搜索结果可按以下维度筛选：传统四部分类（经、史、子、集及道教部、佛教部等）、朝代、现代学科分类
- 书库浏览：按"经部 / 史部 / 子部 / 集部 / 道教部 / 佛教部 / 出土文献部 / 文书档案部"分类逐级浏览，如[集部书库](https://www.shidianguji.com/library/10003)
- 另有专题数据库，如东亚汉文、中华女子艺文、巴蜀历代方志、中国科技典籍、中华饮食文化典籍等
- 阅读和搜索无需登录；参与校对、做笔记、领取整理任务等功能需要注册登录

# 开发者文档

> 以下均为 2026-09 实测。**合规提醒**：[用户服务协议](https://www.shidianguji.com/protocol/page) 第 2.4、4.4、7.5 条禁止未经书面许可的复制、镜像、垂直搜索、"非法抓取、模拟下载、深度链接"及以机器人/蜘蛛程序下载内容；`robots.txt` 仅对白名单搜索引擎（Googlebot、Baiduspider、Bytespider 等）开放，对 `User-agent: *` 为 `Disallow: /`。下文仅记录页面结构，用于单本书的人工辅助查阅与元数据核对，不应用于批量抓取。

## URL 结构

### 书籍首页
```
https://www.shidianguji.com/book/{bookId}
https://www.shidianguji.com/zh/book/{bookId}
```
- `bookId`：书籍 ID，前缀表示来源/丛编，例如（前缀含义据样本推断，待确认）：
  - `SK`：四库全书本（如 `SK1013`《[雍正]陝西通志》）
  - `SBCK`：四部丛刊（如 `SBCK011`《論語》）
  - `LS`：历代正史（如 `LS0016`《舊唐書》百衲本）
  - `GJTS`：古今图书集成（如 `GJTS14`《古今圖書集成·氏族典》）
  - `HY`：哈佛燕京图书馆影像（如 `HY0627`）
  - `NA`：日本内阁文库（国立公文书馆）影像（如 `NA06804`《太平廣記》）
  - `CADAL`、`NGJ`、`DZ`、`JS`、`NLG`、`PC` 等：其他来源；另有纯数字 ID（如 `7372195428416094242`）
- 书籍首页对非浏览器请求只返回空壳（`loaderData` 中仅 `{isSpider, enableWebp}`，`<title>` 为"阅读-识典古籍"），元数据需从章节页取

### 章节阅读页
```
https://www.shidianguji.com/book/{bookId}/chapter/{chapterId}[?version={n}]
```
- `chapterId`：13 位 base36 章节 ID（如 `1kljhqnhef9kk`），从 `bookInfo.catalog` 获取
- `version`：文本版本号（可选），缺省为当前版本；`bookInfo.version` 给出书的当前版本号

## 搜索 API

无公开 API。前端 API 前缀为 `/api/ancientlib/read/...`、`/api/ancientlib/mgt/...`，请求需带字节跳动 SecSDK 生成的 `a_bogus` 签名，手工构造请求返回错误码 `40001`（见 overview 仓 `.claude/skills/fetch-shidianguji` 的实测记录）。

搜索页 `/search/{关键词}` 为服务端渲染，首屏结果嵌在 HTML 的 `window._ROUTER_DATA` 中：

```
loaderData['__session/(lang$)/search.(query$)/page'].data
```

| 字段 | 说明 |
|------|------|
| `paragraphs[]` | 命中段落；每项含 `bookInfo`（书目元数据）、`chapterId`、`chapterNames`、`paragraph.content`（段落 JSON）、`startPage/endPage.pageId` |
| `recommendBooks.books[]` | 推荐书目（`bookId`、`bookName`、`authors`、`edition` 等） |
| `total` / `pageSize` / `pageNum` / `hasMore` | 分页（`total` 上限显示为 1000） |
| `traditionalCateCounter` / `dynastyCateCounter` / `modernCateCounter` | 分面计数（键为分类 ID） |

翻页、筛选走带签名的 XHR，无法直接调用。

## 元数据获取

SPA（Modern.js）+ 服务端渲染。章节页 HTML 内嵌完整数据：

```html
<script>window._ROUTER_DATA = {...}</script>
```

路径：`loaderData['__session/(lang$)/book/$']`，含 `bookInfo`、`paragraphList`、`volume`、`ssrChapterId`、`isSpider`。

- `isSpider: true` 时表示被判为爬虫，只剩 `{isSpider, enableWebp}`；书籍首页总是如此，章节页用普通浏览器 UA 可拿到完整数据
- 大部头书的 `catalog` 极大（如 `GJTS14` 章节页 HTML 约 32 MB）

### 正文（`paragraphList[]`）

每段：`paragraphId`、`chapterId`、`startPageId`/`endPageId`、`content`（JSON 字符串）、`translateContent`（JSON 字符串，可空）。

`content` 解析后为 `{"lines":[{lineType, content, ...}]}`，`lineType` 含义（据 `fetch-shidianguji` skill 实测）：

| lineType | 含义 |
|----------|------|
| 1 | 正文 |
| 2 | 夹注（小字双行注，务必保留） |
| 3 | 页标（通常为空，带 `pagePass.PageId`） |
| 4 | 卷标题 |
| 7 | 著者署名行 |
| 8、9 | 标题类（样本中见于篇名，精确含义待确认） |

`translateContent` 解析后为 `{"sentences":[{logicSentenceId, content}]}`，与原文按 `logicSentenceId` 对应。原文与译文须分开提取。

## 下载

### IIIF / bookget

- 不支持 IIIF
- bookget 是否支持：待确认（未见相关模块，未深入核查）

### 影像

- 影像托管在 `p{N}-ancientlib-sign.byteimg.com`，URL 形如：
  ```
  https://p6-ancientlib-sign.byteimg.com/tos-cn-i-ceu0di7tn2/read/{bookId}/{ver}/page/{...}/{...}.webp~tplv-ceu0di7tn2-png.png?lk3s=e5c95217&x-expires={ts}&x-signature={sig}
  ```
- **带签名、有过期时间**：`x-signature` 改动即返回 403；实测 `x-expires` 约为请求后 40 天
- 部分书籍图片模板为 `tplv-ceu0di7tn2-wm-png:{base64}`，其中 base64 解码为"识典古籍"，即服务端加水印
- 章节页 `bookInfo.previewPages[]` 只给出少量预览页（`pageId`、`picUrl`、`thumbUrl`、`pageNum`）；逐页影像由阅读器通过带签名的 API 按需加载

### 文本

- 无官方导出；网页端复制有次数上限
- overview 仓的 skill `fetch-shidianguji` 记录了用有头浏览器逐章打开章节页、从 `_ROUTER_DATA.paragraphList` 取文本的做法（headless 与直接 HTTP 调 API 均会被拒）。该做法与用户协议第 7.5 条相抵触，仅适用于个人研究中的少量核对；批量获取应先取得站方书面许可（联系邮箱见"关于我们"：guji@bytedance.com）
