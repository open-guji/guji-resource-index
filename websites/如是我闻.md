# 如是我闻

如是我闻（RuShiWoWen）是一个佛教典籍在线阅读与检索平台，主要整理来自 CBETA 等来源的汉文佛典，并提供古文原文、现代白话译文和明确标注的 AI 辅助解读。

- 网站链接：https://rushiwowen.co/
- 分享协议：原典依各数据来源的授权条款；CBETA 资料参见其[版权与使用说明](https://www.cbeta.org/copyright.php)
- 站方说明总收录 4,515 部典籍；公开书目 API 当前可检索约 4,466 部，数量可能随授权和收录状态变化
- 资源类型：汉文佛典全文、现代白话译文、AI 辅助解读
- 不支持 IIIF 协议

## 搜索与浏览

- 全部典籍：https://rushiwowen.co/all
- 可按书名、编号、朝代、作者或译者查找和浏览典籍
- 阅读和公开检索无需注册；收藏、导出等部分功能可能需要登录或会员权限

## 每本书能看到什么

| 字段 | 说明 | 示例 |
|------|------|------|
| 题名 | 典籍名称 | 般若波羅蜜多心經 |
| 编号 | 数据来源中的典籍编号 | T0251 |
| 译者 | 汉译者 | 玄奘 |
| 朝代 | 译者或成书年代 | 唐 |
| 卷与页 | 站内整理的篇章层级 | 第一卷、第 1—2 页 |
| 原文 | 汉文佛典全文 | 觀自在菩薩行深般若波羅蜜多時…… |
| 译文 | 现代白话译文 | 逐段与原文对照显示 |

- 可在线逐段对照阅读原文和白话译文
- 英文、日文等 AI 辅助内容会标明模型与生成时间，并注明不作为权威译本
- 部分典籍支持站内 PDF 或 EPUB 导出，实际权限和可用范围取决于会员状态与原始资料授权
- 不提供古籍影像，主要资源形态为文字

## 示例

- 《般若波羅蜜多心經》：https://rushiwowen.co/r/heart-sutra
- 《金剛般若波羅蜜經》：https://rushiwowen.co/r/diamond-sutra

# 开发者文档

## URL 结构

### 典籍阅读页

```text
https://rushiwowen.co/r/{slug}
```

- `slug`：典籍的稳定英文路径标识，如 `heart-sutra`、`diamond-sutra`

### 作者或译者页

```text
https://rushiwowen.co/by/{name}
```

- `name`：作者或译者姓名，需要进行 URL 编码

### 目录筛选页

```text
https://rushiwowen.co/list/search/{query}
https://rushiwowen.co/list/dynasty/{dynasty}
https://rushiwowen.co/list/person/{name}
```

## 搜索 API

公开 API 无需登录，完整接口定义见 [OpenAPI 文档](https://rushiwowen.co/openapi.json)。

```text
GET https://rushiwowen.co/api/books?page=1&limit=12&search={query}
```

主要参数：

| 参数 | 说明 |
|------|------|
| `page` | 页码，从 1 开始 |
| `limit` | 每页数量，最大 100 |
| `search` | 书名、编号等搜索词 |
| `dynasty` | 朝代筛选 |
| `person` | 作者或译者筛选 |
| `locale` | `zh`、`en` 或 `ja` |

响应的 `data.books` 为书目数组，`data.pagination` 提供总数和分页信息。

## 元数据获取

书目 API 返回 JSON，可直接读取以下字段：

| 中文字段 | JSON 路径 |
|---------|-----------|
| 题名 | `data.books[].title` |
| 编号 | `data.books[].code` |
| 阅读路径 | `data.books[].slug` |
| 作者 | `data.books[].author` |
| 译者 | `data.books[].translator` |
| 朝代 | `data.books[].dynasty` |
| 简介 | `data.books[].description` |
| 数据来源 | `data.books[].collection.code` |
| 卷与页 | `data.books[].volumes[].pages[]` |

已知公开阅读路径还可以转换为 Markdown：

```text
GET https://rushiwowen.co/api/md?_u=/r/heart-sutra
```

该接口返回适合阅读和引用的 Markdown 页面，不代表取得原始数据的再分发授权。

## 下载

- 不支持 IIIF，也不提供古籍影像下载
- 公开书目 API 适合检索元数据，不应视为批量下载接口
- 站内 PDF、EPUB 或原始内容导出受会员权限与单部典籍授权限制
- 引用或再利用原文时，应继续遵守对应数据来源的版权与使用条款
